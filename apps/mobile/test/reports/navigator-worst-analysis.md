# Розбір 150 найгірших випадків симулятора (частина 5.5)

Джерело: `npm run navigator:sim -- 23` (106 260 прогонів), `navigator-sim-worst.json`. Кожен випадок: питання → відповідь → «чому ти так відповів?» (штурман) → причина.

## Групи причин

| Причина | Формулювань | Випадків серед 805 провалів | Що робити далі |

| Категорію не розпізнано: опечатка в ключовому короткому слові (основа < 5 літер без допуску на помилку: «глуш» → «Глуать»; «камер» → «кмаери») | 2 | 322 | Словник типових опечаток / фонетична нормалізація для коротких основ; або мовна модель на сервері |

Усі 805 провалів — 5 формулювань (форми «опечатка» і «голос (шум)») × 7 ситуацій × 23 набори чисел: класифікація не залежить від чисел, тож кожне формулювання провалюється в усіх ситуаціях однаково.
