# NAVIA Architecture

## Runtime
Mobile: React Native + TypeScript + MapLibre Native.
Core: platform-independent TypeScript.
Native: location, motion sensors, voice, background services.

## Data
OpenStreetMap-derived map/routing/POI data.
Online routing/geocoding through provider interfaces.
Offline Kyiv/Kyiv Oblast packages generated by scripts.

## Navigation chain
GNSS -> GNSSMonitor -> SensorFusion -> PositionEstimate -> MapMatcher -> RouteProgress -> LandmarkEngine -> ConfidenceEngine -> AI/Voice.

## Core invariant
AI never generates navigation truth. It only explains NavigationContext.

## Offline invariant
When network is disabled, core navigation continues if the required regional package is installed. The UI must show exactly which capability is offline and which is unavailable.
