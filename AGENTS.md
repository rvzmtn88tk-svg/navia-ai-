# AGENTS.md — NAVIA

Перед любой задачей прочитай:
1. docs/NAVIA_TZ.md — техническое задание, фазы, решения владельца, статусы, формат отчёта.
2. docs/NAVIA_CONSTITUTION.md — продуктовая конституция и детали аудита.

Приоритет при противоречиях: текущий промпт → docs/NAVIA_TZ.md → docs/NAVIA_CONSTITUTION.md → существующий код.

Коротко:
- Одна фаза за раз, после фазы — отчёт и остановка.
- Один агент за раз: не редактировать проект, пока в нём работает другой агент (Codex или Claude).
- Функция либо реальна, либо честно недоступна. Ничего не выдумывать.
- Не ломать: заставку по таймеру, построение маршрута, GPS, переходы, запуск на устройстве.
- Интерфейс — украинский (английский как второй язык), все строки через локализацию. Цвета, отступы, шрифты — только из токенов.
- Не использовать слово «готово». Только статусы: IMPLEMENTED, AUTOMATED-TESTED, RUNTIME-TESTED, DEVICE-VERIFIED, PARTIAL, BLOCKED, NOT IMPLEMENTED.
- Вопросы владельцу — нумерованным списком с вариантами и рекомендацией.
